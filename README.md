# 📚 MY_BOOKSHELF

**Your Personal Digital Learning Library**

MY_BOOKSHELF is an educational platform designed to organize learning resources, books, and study materials in one place. It provides students with convenient access to educational content across different grade levels and subjects.

## ✨ Features

- 📖 **Digital Library** – Access a collection of educational books and PDF resources.
- 🎓 **Grade-Based Learning** – Learning materials organized by grade level.
- 📚 **Subject Collection** – Browse resources by individual subjects.
- 🤖 **AI Chat** – An AI-powered chat interface for learning assistance.
- 🌐 **Learning Website** – A dedicated website for accessing educational resources.
- 📂 **Organized Resources** – Structured folders for easy navigation.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tharompanha1-ops/MY-BOOKSHELF-KH.git
```

### 2. Open the project

```bash
cd MY-BOOKSHELF-KH
```

### 3. Run AI CHAT

```bash
cd "AI CHAT"
npm install
npm run dev
```

Open the local URL displayed in your terminal.
